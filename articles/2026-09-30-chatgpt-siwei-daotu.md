先说结论：别让 ChatGPT 直接「画一张图」，让它输出**带层级的 Markdown 大纲**，再交给工具出图：想马上看贴进 Markmap，要精修存成 .md 导入 XMind，要嵌进笔记就让它写 Mermaid 的 mindmap 代码。免费版就能做。

## 4 种方法怎么选

| 方法 | 推荐指数 | 适合谁 |
|---|---|---|
| Markdown + Markmap | 5/5 | 想马上看到图 |
| Markdown + XMind 导入 | 4/5 | 要交给别人、要打印 |
| Mermaid 代码 | 3/5 | Typora / Obsidian / GitHub 记笔记 |
| 直接生成图片 | 1/5 | 改一个字要整张重画，不推荐 |

## 提示词模板

> 把下面的内容整理成思维导图大纲，用 Markdown 代码块输出。规则：# 是中心主题，只有一个；## 是分支，4 到 6 个；### 是子节点，每个分支 2 到 5 个；最多再往下一层，用「- 」开头。每个节点不超过 12 个字，写关键词不写句子。不要加解释。内容：【粘贴原文】

## 三个翻车点

- **XMind 导入一片空白**：把代码块的反引号也复制进去了，或 # 后面没空格。
- **导入后中文乱码**：.md 另存为 UTF-8 再导入。
- **让它在代码环境里画 PNG，中文全是方框**：运行环境常缺中文字体，改用上面的工具出图。
