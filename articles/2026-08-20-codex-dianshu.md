# Codex 点数怎么算：500 credits 值多少 token、够跑多少任务（2026）

先说结论：Codex 点数（credits）按 **1 点 = 0.04 美元**定价，500 点就是 20 美元、约合 ¥145。值多少 token 取决于模型档：顶配 Sol 约能换 **66 万输出 token**（或 400 万输入 token），按官方"典型任务 5-40 点"折算，500 点够跑 **12-100 个任务**。

## 费率卡（每 100 万 token 扣点）

| 模型档 | 输入 | 缓存输入 | 输出 |
|---|---|---|---|
| Sol（顶配） | 125 点 | 12.5 点 | 750 点 |
| Terra（均衡） | 62.5 点 | 6.25 点 | 375 点 |
| Luna（轻量） | 25 点 | 2.5 点 | 150 点 |

两个规律：输出比输入贵 6 倍；缓存输入只要一折。7 月底 OpenAI 刚降过 API 价，费率卡可能跟调，以官方费率卡为准。

## 省点三招

选对档（机械活用 Luna，消耗是 Sol 的 1/5）；吃缓存红利（同一会话连续干活）；离 Fast 模式远点（更高费率）。

## 订阅额度和点数的关系

Plus/Pro 订阅自带 Codex 用量（5 小时窗+周上限），用完才需要买点；Free/Go 没有买点资格只能升级。判断：偶尔超一次买点数，月月都超升档更划算——Pro 5× 是 Plus 的 5 倍用量、20× 是 20 倍，Codex 高并发正是 Pro 主打。
