# ChatGPT Canvas 怎么用：选中哪段改哪段、代码迭代运行与三件别在画布里做的事（2026）

> 原文（价格实时更新）：https://gptpro20x.com/blog/chatgpt-canvas/

先说结论：Canvas 是 ChatGPT 里专门用来"改"而不是"聊"的工作区，一篇文章或一段代码打开在右侧画布里，你选中哪一段它就只动哪一段。对话模式每改一处都要重新输出全文，Canvas 解决的就是这个。最值钱的三个场景是长文改稿、代码迭代和多版本对比；最不值的是拿它做首稿。

## 怎么开启

输入框「+」里选「画布」；或对话里说"用 Canvas 打开"；或对已生成的长回复点画布图标。免费版能用有次数限制，Plus 起按主力模型额度算。

## 改稿：选中哪段改哪段

| 操作 | 怎么做 | 效果 |
|---|---|---|
| 局部改写 | 选中一段，输入"压到 50 字" | 只改选中部分 |
| 全篇统一 | 左侧对话说"全文把 X 改成 Y" | 整篇处理，看得到 diff |
| 行内批注 | 选中后"添加评论" | 只给建议不直接改 |
| 回退版本 | 右上角历史箭头 | 每次改动一个版本 |

核心习惯：别在对话里说"帮我改一下"，选中具体段落再给具体指令。

## 写代码：迭代比首写合适

代码模式有加注释、加日志、修 bug、转换语言、代码审查五个固定动作。先在对话里生成初版，送进 Canvas 后一个函数一个函数改。Python 和 JavaScript 可以在画布里直接运行。

## 三件事别在 Canvas 里做

写首稿（对话更快）；几万字超长文档（会卡，拆章节）；手机上精修（选中拖动费劲）。

## 常见问题

**免费版能用吗？** 能，有每日次数限制。

**和 Projects 什么区别？** Canvas 是一份内容的编辑区，Projects 是一组对话和文件的容器，Projects 里也能开 Canvas。

**画布图标不显示？** 确认模型支持 Canvas，且不在临时对话里。
